# The Black Door Society

A zero-build literary-horror author site for Jeff's fiction and future reader community.

## Current story slate
1. **The Names We Buried** — Book One / first release
2. **Kasse Clothed** — Book Two / next project
3. **Hollow Guests** — Book Three / in the works
4. **Well Wishes** — Book Four / future project

The current blurbs and visual directions are intentionally early-stage. They establish tone without locking the novels into plot details that have not been supplied yet.

## Artwork
Original scalable vector concept art lives in `assets/covers/`:
- `the-names-we-buried.svg`
- `kasse-clothed.svg`
- `hollow-guests.svg`
- `well-wishes.svg`

These are site concept visuals, not final publication covers. Because they are SVGs they remain sharp on high-resolution and large displays and do not require a stock-image license or external image CDN.

## Site architecture
The public experience is intentionally lightweight and self-contained:
- no paid site builder
- no framework or build step
- no external font/CDN dependency
- responsive editorial horror design
- book-first story funnel
- Black Door Society membership section ready for Patreon later

## Patreon
Patreon is intentionally not connected yet. The public site explains that the community is opening later instead of sending visitors to dead or placeholder membership links.

When the Patreon creator page is ready, the membership calls-to-action can be connected directly.

## Hosting
Recommended long-term host: Cloudflare Pages using this repository and `main` as the production branch, with no build command and the repository root as the site root.

GitHub Pages is also technically suitable for this static build once Pages is enabled in repository settings.

## Kindle Unlimited guardrail
Do not distribute the same digital ebook through the site or Patreon while that title is enrolled in KDP Select/Kindle Unlimited. The future membership experience is structured around community, creative process, readings, eligible bonus/alternate material, cover decisions, and behind-the-scenes access instead.
