# The Black Door Society

A zero-build static author site designed for free hosting on Cloudflare Pages.

## Connect the real links
Edit `assets/config.js`:
- `patreonUrl`: your Patreon creator page
- `amazonAuthorUrl`: your Amazon author page
- `contactEmail`: optional email used by the simple contact form
- `currentProject`: current book title, description, and status

## Add a custom author portrait
Replace the `.portrait` placeholder in the HTML with an `<img>` or add a background image via CSS.

## Host for $0/month
Recommended: Cloudflare Pages. This project is plain HTML/CSS/JS and needs no build command. Upload the folder or connect a Git repository.

## Kindle Unlimited guardrail
Do not use this site or Patreon to distribute the same digital ebook while that title is enrolled in KDP Select/Kindle Unlimited. The site is structured around community, process, readings, selected bonus/alternate material, and behind-the-scenes content instead.
